# Georgia Utilities

Georgia Utilities is a custom Discord bot developed in JavaScript for a community server based in Georgia. The bot was designed to streamline server management, sessions, resources, moderation, and utility functions.

## Features

- Session management system
- Moderation commands
- Ticket system
- Resource commands
- Custom embeds
- Permission-based commands
- Utility tools for staff members

## Built With

- JavaScript
- Node.js
- Discord.js

## Purpose

This project was created to support the day-to-day operations of a roleplay community by reducing manual tasks and providing staff with useful management tools.
